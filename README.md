# Java e Quality Assurance

Este repositório reúne exercícios preparados para as unidades 1 a 4 da disciplina de Quality Assurance em Java. O objetivo é praticar conceitos de qualidade, fundamentos da linguagem e orientação a objetos.

Os arquivos estão organizados por unidade dentro de [quality-assurance-unidades-1-a-4.zip](quality-assurance-unidades-1-a-4.zip). Baixe e extraia o arquivo para abrir os códigos no IntelliJ IDEA; no projeto, mantenha a estrutura de pacotes.

Este material é parte dos estudos. A revisão dos enunciados e a realização dos questionários da plataforma permanecem pendentes.
